# 스마트 주차 앱 (Smart Parking) 공식 배포 저장소

본 저장소는 단지 입주민을 위한 **스마트 주차 층수 및 위치 안내 앱(릴리즈 암호화 버전)** 공식 배포 저장소입니다.

---

## 📥 최신 버전 다운로드 (Direct Download)

아래 링크를 터치하시면 중간 광고나 구글 드라이브 경고창 없이 즉시 최신 버전 APK 파일이 다운로드됩니다:

* **[📥 스마트 주차 앱 최신 버전 다운로드 (app-release.apk)](https://github.com/jeongsomi71-hash/parkingFile/raw/main/app-release.apk)**

---

## 💡 스마트폰 간편 설치 방법
1. 상단 다운로드 링크를 누릅니다.
2. 다운로드가 완료되면 스마트폰 상단바에서 `app-release.apk`를 터치합니다.
3. "출처를 알 수 없는 앱 설치" 안내가 뜨면 **[허용]**을 선택합니다.
4. 앱 설치 완료 후 실행하여 안내받으신 입주민 보안 코드를 입력하시면 바로 시작됩니다:
   * **입주민 코드:** `124124`
