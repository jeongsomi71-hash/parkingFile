## 💡 스마트폰 간편 설치 방법 (3단계)
1. 상단 링크를 눌러 `parking-app.apk`를 다운로드합니다.
   * 브라우저에서 *"유해한 파일일 수 있음"* 팝업 시 → **[무시하고 다운로드]** 선택
2. 다운로드가 완료되면 상단 알림창의 `parking-app.apk`를 누릅니다.
3. *"Play 프로텍트에 의해 차단됨"* 팝업 시 → **[세부정보 더보기]** 클릭 후 **[무시하고 설치]**를 선택합니다.
4. 앱 실행 후 입주민 보안 코드를 입력하시면 즉시 시작됩니다:
   * **입주민 코드:** `124124`
