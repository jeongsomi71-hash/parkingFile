📲 설치 방법 안내 (간단 3단계)
1

다운로드 경고창 발생 시

브라우저에서 "유해한 파일일 수 있음" 창이 뜨면 무시하고 다운로드를 눌러주세요.

2

다운로드 완료 후 파일 열기

화면 상단 알림창의 "parking-app.apk" 또는 브라우저의 열기를 터치합니다.

3

Play 프로텍트 차단 창 발생 시

세부정보 더보기를 누른 후 무시하고 설치를 누르면 정상 설치됩니다.

안심하세요: 구글 플레이스토어를 거치지 않고 웹에서 직접 배포되는 모든 앱에 대해 안드로이드 OS가 기본 표시하는 보안 확인 안내입니다.

✨ 주요 기능
🏢
로비폰 자동 감지
101동 출입 시 B1~B3 층수 즉시 자동 판별
👟
체감 거리 측정
가까움/중간/먼 편 및 10단위 올림 걸음 수 안내
🚗
다차량 지원
4자리 번호 지정 또는 0000(전체 차량) 대응
🔋
초절전 설계
입차 알림 감지 시에만 1~2분 스마트 스캔

현재 101동 정상 동작 중이며, 102동, 103동, 104동은 순차적으로 등록 진행 예정입니다.
